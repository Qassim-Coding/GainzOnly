# GainzOnly, l’app qui fait bosser tes actions pendant que tu chilles 😎💤.

Ajoute tes tickers, vise un prix 🎯, tracke l’écart en live ⚡️📈, et ne rate plus une ex‑date 📅💸.
Inclus: graphiques TradingView 📊, quotes Alpha Vantage, stockage local 💾.

Points clés

Portefeuille : valeur totale, coût, P/L et % par ligne 📈✅/🔻
Wishlist : prix souhaité vs cours, écart % en direct 📊
Dividendes : calendrier ex‑date / date de paiement, vue mois par mois 💰🗓️

📝 Description supplémentaires des composants et du projet

GainzOnly est une application web de suivi d’actions développée avec React et Vite.
Elle permet d’ajouter, modifier et supprimer des actions, de sauvegarder la liste localement et de visualiser des graphiques boursiers via TradingView.

C’est une base de projet évolutive qui servira de fondation pour des fonctionnalités financières avancées (dividendes, calendrier, calculs de performance, etc.).

⚡️ Fonctionnalités principales (V 1.0 - Août 2025)

➕ Ajouter une action à sa liste (ticker, nom, secteur).

✏️ Modifier une action existante.

❌ Supprimer une action après confirmation.

💾 Sauvegarde locale automatique dans le localStorage.

📊 Graphiques intégrés grâce à TradingView (symboles dynamiques).

🎨 Interface responsive avec Tailwind CSS.
