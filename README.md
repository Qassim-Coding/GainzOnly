# GainzOnly l’app qui fait bosser tes actions pendant que tu chilles. 
Ajoute tes tickers, vise un prix, tracke l’écart en live, et ne rate plus une ex‑date. 📈🔥
Inclus: graphiques TradingView, quotes (Alpha Vantage), stockage local.
Points clés

Portefeuille: valeur, coût, P/L et % par ligne.
Wishlist: prix souhaité vs cours + écart %.
Dividendes: calendrier ex‑date / date de paiement.
